Request body

application/json

Property Type Required Description
cloneReports boolean Yes Whether to create clones of the reports from the original dashboard to use on the cloned dashboard (true), or reference the same report objects as the original dashboard (false). Optional, defaults to true.
name string Yes The name of the cloned dashboard.
permissions object Yes
permissions.permissionType enum: EVERYONE_EDIT, EVERYONE_VIEW, PRIVATE, SPECIFIC Yes The type of permission to apply to the report. Valid values are: - PRIVATE: The report is only accessible to its owner and administrators. - EVERYONE_VIEW: The report is viewable by everyone. - EVERYONE_EDIT: The report is viewable and editable by everyone. - SPECIFIC: In addition to the owner, specific users and/or teams are granted VIEW or EDIT permissions. The specificPermissions field must also be present.
permissions.specificPermissions array of object No Array of specific permission grants. Must be present when permissionType is set to SPECIFIC, ignored otherwise. Dashboards can have one or two specific permission configurations: one for VIEW grants and/or one for EDIT grants. Specific users and/or teams receive either VIEW or EDIT permissions based on which configuration they appear in. A given user or team cannot appear in both VIEW and EDIT configurations.
permissions.specificPermissions[].grants array of object No An array of grants detailing the users and/or teams to grant the specific permission to. At least one grantee must be specified.
permissions.specificPermissions[].grants[].grantType enum: TEAM, USER Yes The type of entity to grant permissions to, either USER or TEAM.
permissions.specificPermissions[].grants[].granteeId string Yes The ID of the user or team to grant permissions to.
permissions.specificPermissions[].permissionType enum: EDIT, VIEW Yes The type of permission granted, either VIEW or EDIT.
